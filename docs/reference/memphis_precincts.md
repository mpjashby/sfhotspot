# Memphis Police Department Precincts

A dataset containing the boundaries of Memphis Police Department
precincts.

## Usage

``` r
memphis_precincts
```

## Format

A simple-features tibble with 9 rows and two variables:

- precinct:

  the precinct name

- geometry:

  the boundary of each precinct, stored in simple-features polygon
  format
